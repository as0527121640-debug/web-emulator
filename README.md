# אמולטור אנדרואיד בדפדפן

מכשיר Android 4.4 שרץ על שרת של GitHub, ונפתח בכל דפדפן: מסך המכשיר, ומתחתיו מקשים של מכשיר מקשים.
בלי שום התקנה במחשב.

## הפעלה

1. **Actions** → **אמולטור בדפדפן** → **Run workflow** (אפשר לבחור מסך, משך זמן ומה להתקין).
2. פותחים את הריצה, ובשלב **🔗 הקישור לאמולטור** (או בסיכום הריצה) — הקישור.
3. המכשיר עולה תוך 1–3 דקות; הדף מתחבר בעצמו כשהוא מוכן.

לעצירה לפני הזמן: **Cancel workflow**.

## סיסמה

המאגר ציבורי, והלוגים של הריצות גלויים לכולם. לכן כדאי להגדיר פעם אחת סיסמה:
**Settings → Secrets and variables → Actions → New repository secret**, בשם `EMULATOR_PASSWORD`.
הדף ישאל אותה בפעם הראשונה ויזכור אותה בדפדפן. רק 8 התווים הראשונים נחשבים (מגבלה של VNC).

בלי הסוד — נוצרת סיסמה אקראית, והיא כתובה בתוך הקישור שבלוג (כלומר גלויה למי שנכנס ללוג).

## מקשים

| במחשב | באנדרואיד |
| --- | --- |
| חצים, `Enter`, ספרות | חצים, אישור, ספרות |
| `Esc` | חזור |
| `-` | כוכבית (`*`) |
| `=` | סולמית (`#`) |
| `Ctrl`+`H` | בית |
| `Ctrl`+`M` | תפריט |

אותם מקשים יש גם ככפתורים מתחת למסך. לחצו על המסך לפני הקלדה.
`*` ו-`#` של המחשב מגיעים לאנדרואיד כ-Shift+8 / Shift+3, ולכן מופו `-` ו-`=` (שנמצאים באותו מקום
במקלדת עברית ובאנגלית).

## מה מותקן

- `release` — הגרסה האחרונה של מובידוס מ-[moovitdos/moovidos](https://github.com/moovitdos/moovidos/releases).
- `url` — כל קובץ APK לפי קישור ישיר.
- `none` — מכשיר נקי.

המכשיר חדש בכל הפעלה: מה שהותקן או נשמר בו לא נשאר לפעם הבאה. מזהה-האנדרואיד שלו קבוע
(`4d6f6f7669646f73`, או הסוד `EMULATOR_ANDROID_ID` אם הוגדר), ולכן מזהה-המכשיר שאפליקציה מחשבת ממנו זהה
בכל הפעלה.

## איך זה בנוי

- `start_web_emulator.sh` — מפעיל את האמולטור עם חלון על מסך וירטואלי (Xvfb), שרת VNC שמציג רק את מסך
  המכשיר (x11vnc), ושרת שמגיש את הדף (websockify + noVNC). עובד גם במחשב לינוקס עם Android SDK.
- `web/index.html` — הדף: המסך דרך noVNC, ומקשי המכשיר.
- `.github/workflows/emulator.yml` — מריץ את כל זה על שרת של GitHub (עם האצת חומרה) ופותח לו כתובת
  ציבורית זמנית דרך Cloudflare (`trycloudflare.com`).
